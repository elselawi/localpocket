How to read these numbers

LocalPocket does not aim to be the fastest engine on this chart. It is a local-first database, and every write also persists a durable outbox intent and a sync-state row alongside the domain row — the other engines here write only the domain row, so their write numbers measure a smaller job. Our goal is to stay fast and optimized for the feature set we provide: SQLite-parity reads, indexed queries, transactions, concurrent access, and local-first sync — without sacrificing correctness or durability to chase a rank.
